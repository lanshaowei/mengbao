# 萌宝成长记 👶

> 一个本地优先、隐私安全的婴儿养育一体化记录与提醒应用。
> 所有数据存储在你的浏览器中，不上传任何服务器。

## ✨ 功能模块

| 模块 | 说明 |
|---|---|
| 🏠 **首页仪表板** | 时段问候、今日统计（喂养/尿布/睡眠/待接种）、6 个快捷入口、提醒与近期记录 |
| 👶 **多宝宝管理** | 添加/编辑/切换宝宝，自定义 emoji 头像、性别、生日 |
| 🍼 **喂养记录** | 母乳（左右侧计时器、换边自动分段）、配方奶（奶量）、辅食（食物名） |
| 💉 **疫苗接种** | 中国国家免疫规划 22 剂 +7 类自费推荐，按月龄自动推算；分"即将/逾期/已种"三视图，逾期高亮 |
| 🧷 **尿布记录** | 小便/大便/混合三键速记 |
| 😴 **睡眠记录** | 实时入睡计时器，自动计算时长与睡眠质量 |
| 📏 **成长曲线** | 体重/身高/头围 Canvas 折线图（含渐变填充） |
| ⭐ **成长里程碑** | 16 项常见里程碑（抬头/出牙/叫爸妈/走路…）+ 自定义+照片上传 |
| 💊 **用药记录** | 药品名/剂量/时间/备注 |
| ⚙️ **设置** | 数据 JSON 导入导出、清除全部、浏览器通知授权 |

## 🔐 隐私保护

- 所有记录**仅保存在你的浏览器 `localStorage`**，永远不上传服务器
- 没有任何后端、没有追踪、没有 Cookie
- 卸载浏览器数据会清空记录，请定期使用"设置 → 导出数据"做 JSON 备份
- 可在多浏览器/多设备间通过 JSON 文件互相同步数据

## 🚀 使用方法

直接打开 `index.html` 即可使用（推荐用 Chrome/Edge/Safari 最新版）。
首次访问会引导你添加宝宝，之后就能开始记录。

### 在线版

访问 GitHub Pages：<https://lanshaowei.github.io/mengbao/>

## 🛠 技术栈

- 纯 HTML + CSS + 原生 JavaScript（无构建步骤、无依赖）
- Canvas 2D（成长曲线）
- LocalStorage（数据持久化）
- Notifications API（接种提醒，可选授权）
